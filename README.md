# Sweeper-Check
Utility for remotely checking parking signage in Montreal, built using publicly accessible data.
Data sourced from Montreal's public repository of parking signage data: https://donnees.montreal.ca/dataset/stationnement-sur-rue-signalisation-courant
v0.1 covers the borough of Côte-des-Neiges–Notre-Dame-de-Grâce
Known issues: some small cul-de-sacs (i.e., rue Coronet, rue Piedmont) only list data for one side of the street, despite signage being present on both sides. Be wary if a street seems to only restrict parking on one side.
